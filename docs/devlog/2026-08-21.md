## Technical Learning

* **Local Git repository:** The project history and files stored on the development computer.
* **GitHub remote repository:** The online copy of the repository used for sharing and backup.
* **`origin`:** The conventional name for the primary remote repository.
* **Git branches:** Separate lines of development that keep work isolated from the stable `main` branch.
* **Local changes, commits, and pushes:** Changes edit working files, commits save snapshots to local history, and pushes send local commits to a remote repository.
* **`AGENTS.md`:** Project-level instructions that define scope, technology direction, validation, documentation, and Git workflow expectations.
